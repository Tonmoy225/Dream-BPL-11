# 🏏 Dream BPL 11

**Dream BPL 11** is a fantasy cricket team-building web application inspired by the Bangladesh Premier League (BPL). It provides an interactive interface for exploring cricket players and building your dream team.

🌐 **Live Demo:** [Dream BPL 11](https://keen-piroshki-e27b1a.netlify.app/)

💻 **GitHub Repository:** [Tonmoy225/Dream-BPL-11](https://github.com/Tonmoy225/Dream-BPL-11)

## ✨ Features

- 🏏 **Player Cards:** Display player information in an organized card layout.
- 👤 **Player Details:** View player names, images, origins, roles, batting styles, and bowling styles.
- 💰 **Player Pricing:** Display player prices to support team-building decisions.
- 🖱️ **Interactive UI:** Explore and interact with the player interface.
- 📱 **Responsive Design:** Designed to provide a user-friendly browsing experience across screen sizes.

## 🛠️ Technologies Used

- **React.js** — Component-based UI development
- **TypeScript** — Type safety and improved code maintainability
- **Tailwind CSS** — Utility-first styling
- **JavaScript (ES6+)** — Application logic
- **Vite** — Development server and build tooling

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Tonmoy225/Dream-BPL-11.git
```

**2. Navigate to the project directory**

```bash
cd Dream-BPL-11
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```

## 📂 Project Overview

The application is organized around reusable React components and TypeScript types to keep the code structured and maintainable.

- **Components:** Reusable UI elements, including player cards.
- **Types:** TypeScript interfaces for defining player data.
- **Styling:** Tailwind CSS utility classes for the user interface.
- **Application Logic:** React for rendering and managing interactive UI elements.

## 🎯 Project Goal

The goal of Dream BPL 11 is to practice modern frontend development by building an interactive cricket-themed application using React, TypeScript, and Tailwind CSS.

This project helps demonstrate component-based architecture, typed data handling, reusable UI components, and responsive web design.
